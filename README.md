# 工资核算

GC 门店月度工资计算器。输入总店业绩和各人业绩，自动出工资明细。

线上地址：https://siqiy438-source.github.io/salary-calc/

## 计算规则

| 岗位 | 底薪 | 提成 / 奖金 |
|---|---|---|
| 店长 吴璇 | 8,000 | 总店业绩 × 万分之一 ＋ 个人 A/C/D 千分之二 ＋ 个人 B 千分之一 |
| 销售 小雪、小桃 | 4,500 | 个人业绩满 15 万才有：15 万档 A/C/D 千分之一、B 千分之零点五；20 万档 A/C/D 千分之二、B 千分之一 |
| 财务 朱国坤 | 6,800 | 总店满 60 万：每 10 万奖 200；满 40 万：每 10 万奖 100；不满 40 万无 |
| 配送 邱家斌 | 5,800 | 每趟 15 元 ＋ 与财务相同的业绩奖金 |

底薪构成：销售 = 基本 2,500 + 社保 1,200 + 全勤 500 + 中餐 300；财务 = 5,200 + 1,200 + 100 + 300；配送 = 4,200 + 1,200 + 100 + 300。

两个口径说明：

- 销售档位取**整档**，不是累进。满 15 万不满 20 万走低档，满 20 万整月业绩都走高档。
- 财务、配送的业绩奖金按**每满 10 万**计一次，零头不计（例：65 万 = 6 个 10 万 = 1,200）。

## 怎么改

全部逻辑在 `index.html` 一个文件里，改完 push 就自动更新线上。

- 改比例、底薪：改 `RULES` 对象
- 加人 / 删人 / 改名：改 `STAFF` 数组
- 改规则说明文字：改 `RULETEXT`

填过的数字存在浏览器本地（localStorage），换设备不同步。
